## Project Description

A Job Portal application developed using React and Vite.

The application allows users to explore job opportunities, search and filter jobs, view individual job details, apply for jobs and withdraw applications.

A maximum of 3 job applications is allowed.

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- React Router

## Features

- Dashboard displaying total jobs, applied jobs and remote jobs.
- Search jobs by title, company and location.
- Filter jobs by work mode.
- View individual job details.
- Display required skills and experience.
- Apply for jobs and withdraw applications.
- Maximum limit of 3 applications.
- View all applied jobs.
- Responsive user interface.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/karkichtn/chetan-midsem-phase2.git
```

### 2. Navigate to the project directory

```bash
cd job-portal
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the localhost URL displayed in the terminal.
